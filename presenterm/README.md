# presenterm

ターミナルベースのMarkdownプレゼンテーションツール。

## 起動方法

```bash
# 基本的な起動
presenterm <スライドファイル>.md

# examplesのデモを実行
presenterm examples/demo.md
```

## キー操作

| キー | 動作 |
|---|---|
| `→` / `l` / `PageDown` | 次のスライド |
| `←` / `h` / `PageUp` | 前のスライド |
| `gg` | 最初のスライドへ |
| `G` | 最後のスライドへ |
| `<番号>G` | 指定スライドへジャンプ |
| `Ctrl+P` | スライド一覧 |
| `?` | キーバインド表示 |
| `Ctrl+C` | 終了 |
